Matrix matrix::fromSparseMatrix ( const DYN::SparseMatrix &  sparseMatrix)

convert a dynawo sparse matrix into a matrix to export

The dynawo sparse matrix is stored by columns: so is the converted matrix. The sparse matrix must be complete, i.e. all its columns must have been filled.
